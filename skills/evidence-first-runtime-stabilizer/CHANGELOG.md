# Changelog

## 3.0.0

- Adds beta release-candidate docs and CLI reference.
- Adds incident-state schema and `validate-state` CLI.
- Adds `print-capabilities` CLI for adapter discovery.
- Adds example fixture directories for Docker Compose, systemd and Kubernetes rehearsals.

- Moves private identifier scanning out of source code and into optional caller-provided denylist files.

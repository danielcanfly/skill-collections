# End-to-End Operating Playbook

## A. Dispatch
Handoff Compiler建立identity、manifest、Gate 0、protected baseline、output contract與independence state machine。

## B. Proof-carrying construction
1. Capture immutable source snapshots.
2. Resolve typed locators.
3. Register exact passages and hashes.
4. Decompose proposed knowledge into material clauses.
5. External stage pre-review covers every proposed direct-support clause.
6. Compile direct-support claims only from PASS clauses.
7. Compile nodes from approved claims plus separately labelled bounded synthesis.
8. Compile retrieval outputs using the canonical schema.
9. Execute topic-specific negative fixtures.
10. Seal only after all actual receipts exist.

## C. Admission and Audit
Return admission is mandatory. Candidate self-check is only self-check. Audit OS v6 re-runs canonical validators and verifies stage proof lineage.

## D. Repair
Repair compiler freezes protected surfaces, defines failure-class population selectors and requires external class-wide pre-audit before return.

## E. Global
Global Builder accepts only exact audited production releases, materialises canonical contents, builds G0-G7 and five surfaces. G8 remains PENDING until external global audit.

## v10 External Stage Proof
Direct-support construction requires an external `external_stage_review/STAGE_REVIEW_IDENTITY.json` plus full-population passage and clause review tables. The reviewer ID and Session ID must differ from the Research Builder. A self-filled PASS field is not proof.

# Anonymized Global Semantic/Evidence Seal Lessons

A separate structured decision-analysis domain produced a globally reconciled release whose structural validators passed but later required a semantic/evidence seal. Transferable findings:

1. Many canonical pages can remain semantically templated after ID/graph reconciliation.
2. Claim-source links can exist while evidence boundaries are too weak for direct support.
3. Retrieval benchmarks can leak expected or negative IDs through runner logic.
4. KOS, OKF, R2, production and audit bundles can drift in lifecycle/version metadata.
5. Global repair should preserve canonical identity, rebuild all derived surfaces from one lineage, and retain residual unsupported claims explicitly.

No nodes, claims, sources or examples from that domain are part of this universal profile.

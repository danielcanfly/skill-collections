# V8 to V9 Production Trust-Chain Hardening

V9 closes independently demonstrated V8 bypasses.

## Closed gaps

1. **No-op reproduction:** declared outputs are removed before execution and must be recreated.
2. **Loose audit input:** promotion requires a strict manifest-governed Audit OS v5 evidence package.
3. **Tampered embedded audit:** wrapper validation independently reopens and checks the audit summary, identity, admission, independent review and all hashes.
4. **Unmanifested surface extras:** G8 compares the complete actual file set with manifest entries on all five surfaces.
5. **Audit downgrade:** G8 requires Audit OS v5, contract v9 and exactly six dimensions.
6. **Conflicting identity:** every surface requires one canonical root identity and rejects conflicting IDs elsewhere.
7. **Incomplete proof:** v9 includes a real candidate → Audit OS v5 → promotion → wrapper-validation pipeline test plus fault injection.

## New invariant

A higher-level receipt is accepted only after its underlying governed artifacts are independently reopened and revalidated.

# v10 Agent Usage Recipes

## New research
Generate handoff, complete Gate 0, capture sources, obtain stage pre-review, compile claims/nodes, run pre-return gate, seal, admission, independent Audit.

## Repair
Build handoff with exact source ZIP, audit evidence, protected baseline, allowed-change matrix and failure-class population. Repair Session stops before independent re-audit.

## Global
Supply exact audited production releases. Builder creates provenance capsules, canonical tree, G0-G7 receipts and five surfaces. A separate Global Auditor closes G8.

## v10 External Stage Proof
Direct-support construction requires an external `external_stage_review/STAGE_REVIEW_IDENTITY.json` plus full-population passage and clause review tables. The reviewer ID and Session ID must differ from the Research Builder. A self-filled PASS field is not proof.

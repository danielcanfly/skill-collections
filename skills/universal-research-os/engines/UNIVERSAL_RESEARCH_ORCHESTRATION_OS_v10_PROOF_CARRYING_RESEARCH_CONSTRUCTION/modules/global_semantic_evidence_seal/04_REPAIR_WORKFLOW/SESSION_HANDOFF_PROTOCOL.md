# Session Handoff Protocol

## 派發給 repair session 時

同時提供：

1. 本 Universal OS ZIP。
2. 要修復的 target bundle ZIP。
3. 若有，提供 authoritative audit standard。
4. 指定輸出 domain prefix。

貼上的第一句可使用：

> 請先完整閱讀 `00_PASTE_THIS_PROMPT_FIRST.txt`，再依本 Universal Global Semantic & Evidence Seal Repair OS 對附件中的 Knowledge OS 執行完整 diagnosis、bounded repair、rebuild 與 independent audit。不得重做已穩定的 research phases，也不得修改 live pointer。一次施工至完成並回傳完整 handoff ZIP。

## 收件時必問的不是「做完了嗎」

應核對：

- repair scope decision
- before/after semantic metrics
- evidence boundary distribution
- direct vs bounded claims
- retrieval benchmark hash與contamination receipt
- runner policy
- all-bundle identity matrix
- final P0/P1 findings
- ZIP SHA256

## Repair session 不應交付的東西

- 只有一份文字報告
- 只有修改後 KOS，沒有衍生 bundles
- 只有自測，沒有 independent audit
- 沒有 baseline hash
- 沒有 residual gaps
- 沒有 pointer-change聲明

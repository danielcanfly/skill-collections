# Decision Model

`MERGE_READY` requires all six dimensions to equal 100:

1. Compatibility and contract lineage
2. Semantic evidence
3. Retrieval and leakage resistance
4. Seal and reproducibility
5. External independent semantic verification
6. Production assurance: evidence completeness, metadata completeness, operational depth, portable reproduction, clean release surfaces, and zero open findings

Admission is mandatory. Candidate self-check is never independent evidence. Every retained direct-support material clause, directly used source identity, and directly used locator must receive an external PASS bound to the exact candidate ZIP SHA-256. P0/P1/P2 must equal zero.

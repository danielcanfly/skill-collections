# G5 — Case Reconciliation


## Mission
統一 case identity，將 facts、mechanisms、interpretations、illustrative overlays 與 transfer boundaries 分層。

## Identity unit
同一 public event 不代表所有 analytic overlays 同一 case。依 event scope、time、jurisdiction、evidence layer、analytic purpose 判斷。

## Six-layer assertions
process-fact / contemporaneous-knowledge / outcome-fact / mechanism / retrospective-interpretation / transfer-boundary。

## Mapping
- case → canonical sources/families
- assertion → sources
- assertion → canonical claims（不得回灌 support）
- case → case relations

## Hard gate
所有 local cases mapped；每 active case 六層完整或有 explicit N/A；source IDs only G3；claim IDs only G4；causal boundaries明示；lineage reversible。

## Forbidden
- outcome 證明 mechanism
- illustrative analysis 冒充 fact
- case mapping 膨脹 claim evidence

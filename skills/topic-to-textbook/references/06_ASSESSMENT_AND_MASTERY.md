# Assessment & Mastery Protocol

## Alignment first

Every assessment item must map to a learning objective.

Build an alignment matrix:

`Objective → Lesson → Example/Practice → Assessment`

No orphan questions. No important objectives without any assessment path.

## Assessment levels

### Recall
Can identify / define / list.

### Explanation
Can explain why, how, or compare concepts.

### Application
Can use the concept in a familiar scenario.

### Transfer
Can solve a new scenario with changed constraints.

A serious textbook should not stop at recall.

## Formative checks

Use low-stakes checks during lessons to expose misunderstanding early.

Examples:

- one-minute teach-back
- choose the correct causal chain
- diagnose the wrong model
- complete a missing step
- explain a graph

## Mastery remediation loop

If the textbook supports learning workflow:

1. Formative check
2. Identify failed objective
3. Route to corrective explanation / example / practice
4. Retest with a different item
5. Mark mastery only if the new test is passed without answer leakage

## Answer separation

Questions and answer keys should be separable in the artifact.

If learner sees the answer before attempting the item, do not count that attempt as independent mastery evidence.

## Transfer test design

Good transfer questions change the surface context while preserving the underlying principle.

Avoid trick questions that test ambiguity rather than understanding.

## Quantitative assessment

Check:

- formula correctness
- units
- rounding
- assumptions
- whether the answer key reproduces the same calculation

## Case assessment

A case should specify enough context to make a reasoned decision. If multiple answers are reasonable, score against criteria rather than one hidden preferred answer.

## Teach-back

Use prompts such as:

- Explain this to a non-specialist.
- Explain the difference between A and B without using jargon.
- Walk through the mechanism from input to outcome.
- Explain what would change if assumption X changes.

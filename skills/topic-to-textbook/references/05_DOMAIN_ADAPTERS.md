# Domain Adapters

The universal core controls quality. The adapter controls textbook grammar, source hierarchy, examples, labs and assessment shape.

Choose one primary adapter and optional secondary adapters.

## 1｜AI / ML / LLM

Typical grammar: intuition → model/algorithm concept → data/representation → training/inference → metrics → architecture/pipeline → quality/performance/cost trade-offs → evaluation/safety/failure → examples.

Source emphasis: original papers, model cards, repositories, official framework docs, benchmark definitions.

## 2｜AI Agents / MCP / Tooling

Agent loop → tool/protocol contracts → orchestration → state/memory → permissions/trust boundaries → failure → evaluation → observability → deployment/security.

## 3｜Software / Cloud / Infrastructure / DevTools

Problem → components → architecture/request flow → lifecycle/configuration → failure modes → observability → reliability/scalability/cost → troubleshooting/lab → version notes.

## 4｜Product / PM / Enterprise SaaS

Customer problem → product mechanism → system behavior → metrics → constraints → trade-offs → policy/roadmap options → case → stakeholder communication.

## 5｜Business / Strategy / Business Models

Mechanism → actors/incentives → value creation/capture → revenue/cost engine → competitive dynamics → metrics → boundaries/trade-offs → cases → decision implications.

## 6｜Finance / Accounting / Financial Analysis

Plain-language concept → formal definition → financial-statement location → relationship to other statements/metrics → formula/assumptions → worked numbers → interpretation mistakes → case → decision implications.

Source emphasis: accounting standards, regulators, filings, audited reports, official statistics.

## 7｜Data / Analytics / Experimentation

Question → data-generating process → metric/statistic → assumptions → method → worked calculation → interpretation → bias/failure → experiment/case → transfer.

## 8｜Science / Engineering

Phenomenon/problem → prerequisite physical/scientific model → definitions/laws → mechanism → equations/units → experimental/measurement basis → worked problem → approximation/boundary conditions → uncertainty/error → application.

Source emphasis: peer-reviewed literature, standards, authoritative textbooks/institutions, original datasets, measurement protocols.

Do not simplify away assumptions that determine whether an equation/model applies.

## 9｜Legal / Regulation / Policy

Question/scope → jurisdiction/effective date → governing authority/rule → elements/tests → exceptions → procedure/enforcement → worked fact pattern → competing interpretations → practical implications.

Source emphasis: primary law/regulation, regulator/court/official guidance, then reputable commentary.

Always preserve jurisdiction, effective date, legal status and uncertainty. Educational material is not personalized legal advice.

## 10｜General Conceptual / Academic

Why concept exists → definition → conceptual map → causes/consequences → examples/counterexamples → relationships → misconceptions → application → review.

## 11｜Procedural / How-to

Goal → prerequisites → setup → steps → checkpoints → expected outputs → failure recovery → troubleshooting → verification → safe rollback where relevant.

## 12｜Quantitative / Mathematical

Intuition → notation → assumptions → derivation → fully worked example → completion problems → independent exercises → edge cases → interpretation.

## 13｜Historical / Narrative

Period/scope → timeline → actors → structural context → events → causes/consequences → competing interpretations → primary-source treatment → historiographic uncertainty.

Do not force architecture/failure-mode sections.

## 14｜Language Learning

Communicative goal → vocabulary → pronunciation/script → grammar/pattern → input examples → contrast/common error → guided production → free production → cumulative retrieval.

## Mixed examples

- LLM Serving: primary AI/ML/LLM; secondary Software/Infra + PM
- Unit Economics: primary Finance; secondary Business
- A/B Testing for PMs: primary Data; secondary PM
- MCP Tool Security: primary Agents/MCP; secondary Software/Infra
- Battery Degradation: primary Science/Engineering; secondary Data
- AI Regulation Overview: primary Legal/Policy; secondary AI/ML
